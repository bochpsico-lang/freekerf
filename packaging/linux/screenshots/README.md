# Screenshots

Screenshots of the AppStream metainfo (`io.github.freekerf.FreeKerf.metainfo.xml`),
referenced by their `raw.githubusercontent.com` URL on `main`: Flathub and software
centres download them from there, so a file here is renamed or removed only together
with the metainfo.

- `design.png`: the Design mode, 1600 × 900, dark theme.
- `produce.png`: the Produce mode connected to the built-in emulator with a job made
  from the design, 1600 × 900, dark theme.

Taken from `dev.html` (the UI on the fake service) in Chromium with Playwright.
