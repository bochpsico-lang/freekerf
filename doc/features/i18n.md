# Internationalisation

All UI text goes through [Fluent](https://projectfluent.org/): components call
`t('message-id', {args})` (`ui/web/src/i18n/index.svelte.ts`) and the messages live
in `ui/i18n/<locale>/*.ftl`. "FreeKerf" is never translated.

| File | Content |
| --- | --- |
| `ui/i18n/en/freekerf.ftl` | the reference: every message id, in English |
| `ui/i18n/pt-BR/freekerf.ftl` | Portuguese (Brazil), complete; seeded from the `design` prototype |
| `ui/i18n/de/freekerf.ftl` | German, complete; the long-string test language |
| `ui/i18n/<locale>/lasergrbl.ftl` | **generated** from LaserGRBL's `.resx` translations by `cargo xtask resx2ftl` |
| `ui/i18n/lasergrbl.toml` | which LaserGRBL strings still apply (FreeKerf id → `File.resx:key`) and the pinned LaserGRBL commit |

## Choosing the language

`settings.toml [ui] language`: `auto` (the system's language, the default) or a
locale folder of `ui/i18n` (Settings → Display). Matching is by tag, then by
language (`pt-PT` → `pt-BR`, `de-AT` → `de`, anything else → `en`). A missing
message falls back to English, then to the id. The language picker shows the share
of messages a locale translates when it is not complete.

## Reusing LaserGRBL's translations

LaserGRBL ships 20 languages. Its strings that mean the same thing in FreeKerf
(Connect, Unlock, Resume Job, Header/Footer…) are mapped in `ui/i18n/lasergrbl.toml`;
`cargo xtask resx2ftl --lasergrbl <checkout>` reads the `.resx` files at the pinned
commit (`git show`, so a partial clone is enough), removes accelerator `&` and
trailing colons, and writes `lasergrbl.ftl` for every culture, skipping messages the
locale's `freekerf.ftl` already has. CI runs it with `--check`. The 17 locales that
FreeKerf does not translate itself (es, fr, it, ja-JP, zh-CN…) start partial and fall
back to English; strings whose LaserGRBL translations often meant something else
(`MacStatusConnecting`, `MacStatusJog`) are left out on purpose.

## Rules

- Never concatenate sentences; use placeholders (`{ $n }`).
- Add every new id to `en`, `pt-BR` and `de` (a test fails otherwise).
- Labels wrap instead of being cut; only tabs and table rows use an ellipsis with
  a `title` (`design/interaction.md` §7).

## Tests

- `ui/web/src/i18n/i18n.test.ts`: locale matching, fallback, the locales of
  `ui/i18n` (with LaserGRBL ones), `en`/`pt-BR`/`de` complete, every literal
  `t('…')` id of the code exists in English.
- `ui/web/tests/web/long-strings.spec.ts` (Playwright, Chromium): in German at
  1366, 1000 and 400 px, no control of the shell or of the settings dialog clips its
  text and the page never scrolls sideways (with a check that the detector works).
- `tools/xtask/src/resx.rs` unit tests (reading `.resx`, cleaning, Fluent escaping);
  CI `resx2ftl --check`.
